# Student Data Organizer

## Project Overview

Student Data Organizer is a simple menu-driven Python project that helps users manage student information easily.

Users can add, view, update, and delete student records using a simple console interface.

This project is developed for beginners to understand basic Python programming concepts.

## Features

1. **Add Student** – Add new student details.
2. **Display All Students** – View all registered student records.
3. **Update Student Information** – Update student details using Student ID.
4. **Delete Student** – Remove student records.
5. **Display Subjects Offered** – Display all unique subjects entered for students.
6. **Exit** – Close the program.

## Student Details

The program collects the following information:

- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects
